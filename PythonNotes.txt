Advantages of Dictionary:
Fast lookup using keys (average time complexity O(1)).
Easy to store related data.
Mutable (can be modified).
Can store different data types.
Supports nesting for complex data structures.
Widely used in APIs, JSON data, databases, and configuration files.

Limitations of Dictionary:
Keys must be unique.
Keys must be immutable (e.g., strings, numbers, tuples containing immutable elements). Lists and other dictionaries cannot be keys because they are mutable.
Dictionaries are not indexed by position like lists. You access values using keys, not numeric indexes.

Interview Questions
1. What is a decorator?

A decorator is a function that takes another function as input, adds additional functionality, and returns a modified function without changing the original function's source code.

2. Why do we use decorators?

To add reusable features such as logging, authentication, caching, validation, or timing while keeping the original function unchanged.

3. What does @decorator mean?

It is syntactic sugar for:

function = decorator(function)
4. Why use *args and **kwargs in decorators?

They allow the decorator to work with functions that accept any number of positional and keyword arguments.

5. Why use functools.wraps?

It preserves the original function's metadata, such as its name, docstring, and annotations.

Interview Questions
1. What is a generator?

A generator is a function that uses the yield keyword to produce values one at a time while preserving its execution state.

2. What is the difference between return and yield?
return ends the function and sends back a value.
yield sends back a value but pauses the function so it can continue later.
3. Why are generators memory efficient?

They generate values only when requested instead of storing all values in memory.

4. What happens after all values are yielded?

The generator raises a StopIteration exception, which is handled automatically by a for loop.

5. What is a generator expression?

A generator expression creates a generator object using parentheses:

squares = (x*x for x in range(10))

It works like a list comprehension but generates values lazily.

An iterator is an object that returns one element at a time from a collection using the next() function.

2. What is an iterable?

An iterable is any object that can be converted into an iterator using the iter() function.

3. What is the difference between an iterable and an iterator?
An iterable is a collection (such as a list or tuple).
An iterator is an object that retrieves elements from the iterable one by one.
4. Which methods must a custom iterator implement?

A custom iterator must implement:

__next__()

StopIteration is the exception raised by an iterator when there are no more items to return.

3. np.empty()

This is one of the most misunderstood functions.

Many beginners think it creates an empty array.

❌ Wrong.

It creates an array without initializing the values.

That means NumPy simply reserves memory and whatever values were already in that memory are shown.

np.full()

Q1. Why does np.zeros() return floats by default?

Answer: NumPy defaults to float64 unless you specify a different dtype, because floating-point numbers are common in
 scientific and numerical computing.

 Q2. What's the difference between zeros() and empty()?
zeros() initializes every element to 0.
empty() only allocates memory; the values are uninitialized and unpredictable until you overwrite them.

np.empty() does NOT guarantee random values.

What np.empty() actually does is:

It allocates memory for the array.
It does not initialize the values in that memory.

So whatever data already exists in that memory location is what gets displayed.

Why is np.empty() faster than np.zeros()?

Answer:

np.empty() is faster because it only allocates memory and does not initialize the array elements. In contrast, np.zeros() allocates memory and then 
writes 0 to every element, which takes additional time.

Answer: Because linspace() avoids many floating-point precision issues by generating a specified number of evenly spaced values.

Broadcasting is NumPy's mechanism for performing arithmetic operations on arrays of different shapes by automatically expanding the 
smaller array whenever possible.
A very common interview question is:

Why is broadcasting useful?

Answer:

It avoids writing loops.
It is much faster because operations are implemented in optimized C code.
It avoids creating unnecessary copies of data, making code more memory-efficient.
